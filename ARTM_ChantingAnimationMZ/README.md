# ARTM_ChantingAnimationMZ
指定IDのアニメーションを詠唱者に表示するMZ専用プラグインです。
詠唱中はループ再生で表示し続けることが出来ます。

【補足】下記条件を満たすと、絵が途切れることなくループ再生可能です。
- アニメーションの先頭フレームと末尾フレームの絵が繋がっていること
- 本プラグイン導入後、対象スキルのメモ欄に1ループの終了フレーム(※1）を記載すること。<br>
（※1.アニメーションによって終了フレームの設定値は異なります。記載方法についてはプラグインのヘルプをご参照下さい。）
