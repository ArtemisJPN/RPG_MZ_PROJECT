# シームレス詠唱アニメーション表示プラグイン
<br>
スキル詠唱中、アクターや敵キャラに指定IDのアニメーションを途切れず滑らかにループ再生させるプラグインです。  <br>
通常のループ処理と異なり、つなぎ目のカクつきがない自然な回転・発光演出を実現できます。

---

## 主な特徴

- **途切れのないシームレスループ**  
  魔法陣やオーラなど、回転・明滅し続けるエフェクトがスムーズに回り続けます。
- **「出現（フェードイン） → メインループ」の2段階演出**  
  詠唱開始時にアニメーションが徐々に現れ、その後そのまま途切れることなくループ回転を維持するような演出が可能です。
- **メモ欄への簡単タグ設定**  
  スキルのメモ欄に短いタグを追記するだけで即座に適用できます。

---

## 導入の前提条件（きれいに見せるコツ）

本プラグインで途切れのない綺麗なループを行うため、以下の点をご確認ください。

1. **アニメーション素材の仕様**  
   使用するアニメーションの**先頭フレームと末尾フレームの絵が繋がる（つなぎ目がない）素材**をご用意ください。
2. **終了フレームの設定**  
   アニメーションによって全体のフレーム数が異なるため、スキルのメモ欄に「何フレーム目でループさせるか」を指定する必要があります。
