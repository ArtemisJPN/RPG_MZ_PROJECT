# ARTM_ChantingAnimationMZ
指定IDのアニメーションを詠唱者に表示するMZ専用プラグインです。
詠唱中はループ再生で表示し続けることが出来ます。

【注意点】
下記動画のように途切れることなくループ再生するには下記条件をすべてクリアする必要があります。
- 動画の先頭フレームと末尾フレームの絵が繋がっていること
- Effekseerツールを使用し、対象のアニメーションの開始時間をマイナス値にすること。
- 本プラグイン導入後に対象スキルのメモ欄に終了フレーム(※1）を記載すること。記載方法は本プラグインのヘルプ参照。<br>
※1：末尾フレームより小さい値を設定すること。
