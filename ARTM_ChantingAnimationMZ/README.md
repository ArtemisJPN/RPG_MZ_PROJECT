# ARTM_ChantingAnimationMZ
指定IDのアニメーションを詠唱者に表示するMZ専用プラグインです。
詠唱中はループ再生で表示し続けることが出来ます。

【注意点】途切れることなくループ再生するには下記条件をすべてクリアする必要があります。
- アニメーションの先頭フレームと末尾フレームの絵が繋がっていること
- 本プラグイン導入後に対象スキルのメモ欄に終了フレーム(※1）を記載すること。記載方法は本プラグインのヘルプ参照。<br>
※1：必ず末尾フレームより小さい値を設定すること。

【例】Effekseerツールの再生バーで、開始：2、終了：122 の状態で綺麗にループ再生する場合
- Effekseerツールで共通タブから再生開始時間を-2に、生存時間を120に設定し、保存する。
- RPGツクールMZを起動し、Effekseerツールで編集した上記エフェクトを、アニメーションID125に設定する。
- 本プラグイン導入後に、対象スキルのメモ欄に、「<CA_INFO:ID125,<b>ED_FRAME113</b>>」を記載する。
