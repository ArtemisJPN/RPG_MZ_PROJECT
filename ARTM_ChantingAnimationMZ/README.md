# シームレス詠唱アニメーション表示プラグイン
<img width="814" height="623" alt="ステート画面" src="https://github.com/ArtemisJPN/RPG_MZ_PROJECT/blob/main/ARTM_ChantingAnimationMZ/ChantingAnime.png"/>
スキル詠唱中、アクターや敵キャラに指定IDのアニメーションを途切れず滑らかにループ再生させるプラグインです。  <br>
通常のループ処理と異なり、つなぎ目のカクつきがない自然な回転・発光演出を実現できます。

---

## 主な特徴

- **途切れのないシームレスループ**  
  魔法陣やオーラなど、回転・明滅し続けるエフェクトがスムーズに回り続けます。
- **「出現（フェードイン） → メインループ」の2段階演出**  
  詠唱開始時にアニメーションが徐々に現れ、その後そのまま途切れることなくループ回転を維持するような演出が可能です。
- **メモ欄への簡単タグ設定**  
  スキルのメモ欄に短いタグを追記するだけで即座に適用できます。

---

## 導入の前提条件（きれいに見せるコツ）

本プラグインで途切れのない綺麗なループを行うため、以下の点をご確認ください。

1. **アニメーション素材の仕様**  
   使用するアニメーションの**先頭フレームと末尾フレームの絵が繋がる（つなぎ目がない）素材**をご用意ください。
2. **終了フレームの設定**  
   アニメーションによって全体のフレーム数が異なる為、スキルのメモ欄に「何フレーム目でループさせるか」を指定してください。
3. **Effekseer側の設定**  
   アニメーションのループ時に「一瞬消える・途切れる（ぶつ切り）」場合は、
   Effekseer側で以下の設定を行ってください。<br>
   　(1) ノードの「共通」パネルを開きます。<br>
   　(2)「生成開始時間」の中心に【負の値（例: -2 など）】を入力して保存します。
