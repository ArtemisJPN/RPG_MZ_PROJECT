# ARTM_ChantingAnimationMZ
スキル詠唱者に指定IDのアニメーションをループ再生することで、詠唱中のエフェクト演出が可能になるMZ専用プラグインです。<br>
通常のループ再生と違い、途切れることなく※ループ再生することが出来ます。<br>
また、フェードイン→メインループ と言った演出も可能です。<br>
<br>
【※】下記条件を満たすことが必要です。
- アニメーションの先頭フレームと末尾フレームの絵が繋がっていること。
- 本プラグイン導入後、対象スキルのメモ欄に指定したアニメーションの終了フレームを記載すること。<br>
  （アニメーションによって終了フレームの設定値は異なります。記載方法についてはプラグインのヘルプをご参照下さい。）
