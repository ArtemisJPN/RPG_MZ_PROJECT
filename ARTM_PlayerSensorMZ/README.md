# 現在ご報告を受けている現象について
- 非探索者イベントA｛実行内容：スイッチxxxxをON → プラグインコマンド「探索開始」｝、探索者イベントB｛起動条件：スイッチxxxx ON｝の条件時、イベントAが実行されたあとイベントBが起動された場合、イベントBの探索が開始されない。<br>
→ 上記現象はイベントAで、スイッチxxxxをONの直後にウエイト1フレームを実行することで対処できます。
- 本プラグインのパラメータ「探索範囲X拡張」と「探索範囲Y拡張」を0.5未満に設定すると、扇範囲内を移動中に発見状態とロスト状態を繰り返す為、対策して欲しい。<br>
→ 上記対策は、ver1.1.4で対応済です。<br>
- 「うなぎおおとろ」様作のドット移動システムと併用する場合の注意点
  - 「探索範囲X拡張」「探索範囲Y拡張」は必ず <b>0.5</b> 以上（ <b>0.999</b> 推薦） を設定して下さい。
  -  発見時の移動ルート設定には、必ず「this.dotMoveToPlayer();」のスクリプトをご使用下さい。<br>
  「this.moveStraight(this.findDirectionTo($gamePlayer.x,$gamePlayer.y));」はエラーとなります。<br>
   これはドット移動システムで使用している「1379」斜め方向値に対して、本プラグインがBitmap生成処理を実装していない為です。
