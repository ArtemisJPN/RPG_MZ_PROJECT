# 報告頂いた現象等について
- イベントA｛ 実行内容：スイッチxxxxをON → プラグインコマンド「探索開始」 ｝<br>イベントB｛ 起動条件：スイッチxxxx ON ｝の条件でイベントAが実行された場合、イベントBの探索が開始されない。<br>
→ イベントAを｛ 実行内容：スイッチxxxxをON → ウエイト1フレーム → プラグインコマンド「探索開始」 ｝のように、ウエイトを入れると探索が開始されます。

- 「うなぎおおとろ」様作のドット移動システムと併用する場合の注意点
  - 本プラグインのパラメータ「探索範囲X拡張」「探索範囲Y拡張」には必ず <b>'0.999'</b> を設定して下さい。
  -  発見時の移動ルート設定には、必ず「this.dotMoveToPlayer();」等のドット移動システム専用スクリプトをご使用下さい。<br>
