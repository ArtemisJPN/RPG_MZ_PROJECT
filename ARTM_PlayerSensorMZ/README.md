# 現在ご報告を受けている現象について
- 通常イベントAで、スイッチxxxxをON、プラグインコマンド「探索開始」の順に実行した際、起動条件｛スイッチxxxx ON｝の探索イベントBが起動された場合、探索が開始されない。<br>
→ 上記現象は通常イベントAで、スイッチxxxxをONの直後にウエイト1フレームを実行することで対処できます。
- 本プラグインのパラメータ「探索範囲X拡張」と「探索範囲Y拡張」を0.5未満に設定すると、扇範囲内を移動中に発見状態が度々切れるため対策して欲しい。<br>
→ 上記対策は、ver1.1.4で対応済です。<br>
- 「うなぎおおとろ」様作のドット移動システムと併用する場合の注意点
  - 「探索範囲X拡張」「探索範囲Y拡張」は必ず <b>0.5</b> 以上に、できれば <b>0.999</b> を設定して下さい。
  -  発見時のカスタムルート移動には必ず、「this.dotMoveToPlayer();」のスクリプトをご使用下さい。<br>
    ドット移動システムでは1379の斜め方向値を使用していますが、本プラグインでは斜め方向値が未対応の為エラーとなります。
