# 1. ARTM_InfluenceActorFaceMZ.js
戦闘中のHP・MP・TP残量やステート変化に合わせて、アクターの顔画像をリアルタイムに切り替えるプラグインです。

## 特徴とできること
- **手軽なメモ欄記述**：アクターのメモ欄に簡単なタグを書くだけですぐに動作します。
- **直感的な優先度管理**：メモ欄の上側に書いたタグほど優先して表示されます。
- **切り替えトリガーの種類**：
  - 💔 **HP**：残り割合（%以下）でピンチ顔に
  - 💧 **MP**：残り割合（%以下）で息切れ顔に
  - 🔥 **TP**：指定値以上で気合・覚醒顔に
  - 💫 **ステート**：毒、睡眠、魅了などの専用表情に
  - 🚩 **スイッチ**：バトルイベントや特定フェーズ進行時の表情変化に
- **プリロード機能（オプション）**：戦闘開始時に画像を先行読み込みし、切り替え時のチラつきや表示遅延を防止します。

## 設定イメージ（メモ欄）
```text
<IAF_ST:4,ActorCustom,7>    // ステート4にかかったら顔画像ファイル「ActorCustom」の7番目の顔（最優先）
<IAF_HP:20,ActorCustom,2>   // HP20%以下なら顔画像ファイル「ActorCustom」の2番目の顔（ピンチ）
<IAF_TP:100,ActorCustom,3>  // TP100以上なら顔画像ファイル「ActorCustom」の3番目の顔（気合）
 ```

# 2. ARTM_InfluenceEnemyImageMZ.js
指定ステートにかかった時に、エネミーの立ち絵画像を自動変更します。
