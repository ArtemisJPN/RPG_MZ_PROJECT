# プラグイン紹介
- プラグイン構成
  - ARTM_InfluenceActorFaceMZ.js<br>
    アクターが下記の条件を満たすと、バトルステータス画面の顔画像を自動変更します。
    - HP/MPが指定%以下に変化した時
    - TPが指定値以上に変化した時
    - 指定ステートにかかった時
 
    顔画像を戦闘開始時にプリロードすることで、顔画像変更をシームレスにすることもできます。（オプション機能）
  - ARTM_InfluenceEnemyImageMZ.js<br>
    指定ステートにかかった時に、エネミーの立ち絵画像を自動変更します。
