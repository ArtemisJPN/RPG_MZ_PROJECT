## プラグイン紹介
- プラグインパラメータで指定したショートカットキーか、ボタンアイコンを押すと
<br>対象者(味方or敵）のステート・バフ確認画面を開きます。
- ステートの詳細情報を表示することができ、ツクールMZのデータベースから取得した情報を自動で表示します。<br>
  指定ステートのメモ欄にタグを記述することで、独自の情報を表示することもできます。（この情報は最上段に表示）<br>
  なお、タグについてはヘルプをご参照ください。
- 各タイトル文言（"解除条件" など）はプラグインパラメータで変更可能です。
- 残りターンの表示は、テキスト表示形式と、バッチ表示形式（ステートアイコンの右下に小さく表示）の選択が可能です。<br>

## 競合情報
- 木星ペンギン様作 「MPP_Pseudo3DBattle」と併用する場合 → 拙作「ARTM_StatePopCmd_Patch001」を導入して下さい。
- NUUN様作「NUUN_BattleStyleEX」と併用する場合 → 拙作「ARTM_StatePopupCommandMZ_NUUN_Patch」を導入して下さい。
