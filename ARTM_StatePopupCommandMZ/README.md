# プラグイン紹介
- プラグインパラメータで指定したショートカットキーか、ボタンアイコンを押すと
<br>対象者(味方or敵）のステート・バフ確認画面を開きます。
- ステートの詳細情報を表示することが出来ます。
- 「解除条件」などと言った、各タイトル文言はプラグインパラメータで変更可能です。
- 残りターンの表示はテキストのほか、アイコンの右下に残ターンの数値を小さく表示するアイコンバッチ表示が可能です。
