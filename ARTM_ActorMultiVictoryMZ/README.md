# プラグイン紹介
勝利モーションを拡張するMZ専用プラグインです。
- 基本機能
  - 勝利モーションを別タイプ(詠唱、睡眠 等)のモーションに変更可
  - 勝利モーションを複数指定可 <例> 勝利2回⇒詠唱⇒睡眠⇒(睡眠を無限ループ)
  - 1モーションのスプライト枚数を拡張可能
  - 勝利モーション中に別のアクター画像ファイルへ即時切替可能
- 追加機能
  - 【Ver1.5】1モーションのスプライト枚数を最大54枚に増加。1ループ54枚の勝利モーションを表示できます。
- <b>注意事項</b>
  - Ver1.5からタグの仕様が一部変わっていますので、古いバージョンをお使いの場合はヘルプをご参照ください。
