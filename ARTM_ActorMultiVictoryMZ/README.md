# プラグイン紹介
勝利モーションを拡張するMZ専用プラグインです。
- 基本機能<BR>
  - 勝利モーションを別タイプ(詠唱、睡眠 等)のモーションに変更可<BR>
  - 勝利モーションを複数指定可 <例> 勝利2回⇒詠唱⇒睡眠⇒(睡眠を無限ループ)<BR>
  - 1モーションのスプライト枚数数を拡張可能<BR>
  - 勝利モーション中に別のアクター画像ファイルへ即時切替可能<BR>
