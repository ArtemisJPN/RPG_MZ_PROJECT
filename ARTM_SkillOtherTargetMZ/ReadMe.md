## 概要

スキル使用時にターゲットの選択肢からスキル使用者を除外できるプラグインです。<br>
類似プラグインと異なり、**味方がターゲットの場合に表示されるアクター選択ウィンドウから、スキル使用者の表示を消す**ことができます。<br>
(スキル使用者のSVアクターについて：表示は消えませんが、対象から除外しているため選択ができない状態となります。）

以下のUIに連動します。

- バトル中の選択点滅UI（タッチ操作を含む）
- メニュー画面の対象アクターリスト

## 使い方

スキルのメモ欄に、以下のタグを記述するとスキル使用者を除外できます。

```text
<SOT_STATE:VALID>
```

## 競合情報
NUUN様作「NUUN_BattleStyleEX」と併用する場合 → 拙作「ARTM_SkillOtherTargetMZ_PatchNUUN」を導入して下さい。
