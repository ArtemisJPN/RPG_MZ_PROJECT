# 使用上のご注意
- 本リポジトリでは、当方が作成したツクールMZ用プラグイン（以降は「本プラグイン」と記載）を公開しております。
- 本プラグインはMITライセンスの範囲内で使用可能です。
- 当方は、本プラグインの使用により発生した如何なる責任を負わないものとしますが、<br>本プラグインのバグ報告や機能追加依頼に関しては、可能な限り対応致します。その際はプルリクエスト頂けますと幸いです。

# プラグイン一覧
| プラグイン名 | 機能の概要 |
| ----------- | --------- |
| ARTM_ActorMultiVictoryMZ | ・バトル勝利時に対象者（アクター）の勝利ポーズを他のポーズに変更することが出来ます。<br>・勝利2回→素振り1回→眠りポーズ のようにカスタマイズしたり、即座に別のアクター画像へ切り替えることもできます。<br>・最大で54枚のスプライトを再生させて、オリジナル勝利モーションを作成する事もできます。<br>※砂川赳様作 DynamicMotionMZ との競合対策済み |
| ARTM_ChantingAnimationMZ | バトル中にスキル詠唱中の詠唱者（アクター/エネミー）へ指定IDのアニメーションを表示し続けることが出来ます。 |
| ARTM_DispStatusInBattleMZ | バトル中に対象者（アクター/エネミー）のステータスや状態異常をウインドウ画面で表示するスキルが使用出来るようになります。 |
| ARTM_InfluenceActorFaceMZ | バトル中に対象者（アクター）が特定の状態になった時に、自動で顔画像を変更することが出来ます。<br>特定の状態とは、HPが最大値HPの指定%を下回った時や、MPが最大値MPの指定%を下回った時や、指定のステート状態になった時です。 |
| ARTM_InfluenceEnemyImageMZ | バトル中に対象者（エネミー）が指定のステート状態になった時に、自動で立ち絵画像を変更することが出来ます。<br>本プラグインは、ARTM_InfluenceActorFaceMZフォルダ内に格納されています。 |
| ARTM_InsertOpeningMapMZ | ゲーム起動時のタイトル画面表示前に、オープニングイベントを追加することが出来ます。 |
| ARTM_PlayerSensorMZ | **[MZ移植]** マンカインド様が作成されたプレイヤー探索プラグインのツクールMZ移植版です。<br>プレイヤーがイベントの範囲内に入ると追跡されるといった、ステルス系ゲームを作成出来ます。 |
| ARTM_SkillOtherTargetMZ | 「自分以外の味方」を選ぶ際、アクター選択の点滅カーソルから詠唱者自身を綺麗に除外できます。<br>単に対象から省くだけでなく、バトル中の選択点滅UI（タッチ操作含む）やメニュー画面の対象リストまで違和感なく連動するのが大きな特徴です。<br>スキルのメモ欄に簡単なタグを記載するだけで利用可能です。 |
| ARTM_StatePopupCommandMZ | バトル中にステート確認アイコンボタンorショートカットキーを押すことによりステート確認ウィンドウを開き、対象者のステート情報一覧（残りターン等）と詳細（解除条件等）を確認できます。 |
| ARTM_TMDescriptionExMZ | **[MZ移植]** tomoaky様が作成された詳細説明ウィンドウプラグインのツクールMZ移植版です。<br>アイテムやスキルの詳細情報を表示する機能が使えるようになります。 |
| ARTM_TMEventItemExMz | **[MZ移植]** tomoaky様が作成されたアイテム選択拡張プラグインのツクールMZ移植版です。<br>アイテム選択の処理にヘルプウィンドウを追加し、個数表示の有無と表示行数をアイテムタイプごとに設定出来ます。 |
| ARTM_TMGreedShopMZ | **[MZ移植]** tomoaky様が作成された欲張りショッププラグインのツクールMZ移植版です。<br>お金以外にアイテムも要求されるショップ機能が使えるようになります。 |
